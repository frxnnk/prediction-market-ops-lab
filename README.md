# Prediction Market Ops Lab

An independent, safety-first reference implementation inspired by lessons from a private Polymarket side project built with friends.

This repository is intentionally designed around operational reliability rather than trading performance. It uses synthetic data by default, supports public read-only Gamma/CLOB requests, and contains no code path for placing orders, cancelling orders, bridging assets, withdrawing funds, or transferring funds.

## Status

Local implementation in progress. No remote repository or deployment has been created.

## Non-goals

- Real-money trading
- Proprietary trading strategies
- Performance or profitability claims
- Production wallets, users, trades, infrastructure, or screenshots
